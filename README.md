## 4. 怎么用讲义（Notebook 使用要点）

1. **从上往下跑，不要跳格。** 讲义后面的格子里会用到前面定义的函数（比如 `show_img`），
   跳着跑必然报 `NameError`。
2. **卡住了先重跑一次。** 菜单 `Kernel → Restart & Run All` 是万能第一招。
3. **代码里的路径都是相对路径**（写成 `res/xxx.png`）。
   所以打开 notebook 时，**工作目录要落在 `视觉教材opencv部分/` 这一层**。
   最省事的做法：**用 VS Code / Jupyter 打开整个仓库文件夹**，再点开 notebook。
4. **看到 ⚠️ 标记就停一下。** 那是易错点，讲义故意标出来的。
5. **图片路径不要带中文。** 这是 Windows 上的经典坑，讲义第 1 章专门讲了原因和绕法。

## 5. 练习与答案怎么用（重要）

每章末尾都有「**✍️ 练习**」。答案是**独立文件**（`cv1_练习答案.ipynb` / `cv2_练习答案.ipynb`）。

**正确的用法：**

```text
先自己写  →  跑出来看结果  →  对不上再翻答案  →  看懂思路后关掉答案重写一遍
```

**错误的用法：** 打开答案从头 Run 到尾，以为自己会了。

> 答案里每一步都有**真实运行输出和配图**，是给你**对照结果**用的，不是给你抄的。
> 大作业尤其如此 —— 抄出来的代码，答辩时问一句「你为什么这么写」就露馅了。

## 7. 新人最容易踩的坑（先来这里找）

| 报错 / 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'cv2'` | **内核选错了**（用了系统自带 Python） | 右上角切换成你 Assignment-0 配的 conda 环境 |
| `AttributeError: 'NoneType' object has no attribute 'shape'` | `imread` 没读到图，返回了 `None` | 检查路径拼写；**路径别带中文**；确认文件真的在 `res/` 里 |
| `res/xxx.png` 明明存在却读不到 | **工作目录不对**（相对路径是相对"当前目录"，不是 notebook 所在目录） | 用 VS Code 打开整个仓库文件夹，再点开 notebook |
| 中文路径读图 / 存图失败 | `cv2.imread` / `imwrite` 在 Windows 上不支持中文路径 | 讲义**第 1 章**讲了：用 `np.fromfile` + `cv2.imdecode` 读、`cv2.imencode` + `tofile` 写 |
| `FileNotFoundError: out/xxx.png` | 还没生成 `out/` 目录 | 讲义第一个代码格会 `os.makedirs('out', exist_ok=True)`；跑一遍它，或自己建一个 `out/` |
| 写出来的视频 **0 字节** / 打不开 | `VideoWriter` 的 `frameSize` 写成了 `(高, 宽)` | 顺序必须是 **`(宽, 高)`** —— 和 `img.shape` 反着 |
| 视频存出来了，但**播放器打不开** | 用了 `MJPG` 的 `.avi`，很多播放器不支持 | 改成 **`.mp4` + `mp4v`**（讲义和示例里都是这么写的） |
| `NameError: name 'show_img' is not defined` | 跳格跑了 | `Restart & Run All`，从上往下跑 |
| 图里的中文变成方框 | matplotlib 没配中文字体 | 讲义起手式里已经设好了，别删那几行 |
| 找不到 `dataset/` | 数据集 1.6 GB，**不在仓库里** | 找学长要；YOLO 教材 2.3 节讲了怎么放 |
| `git clone` 报 404 | 私有仓库，你的账号还没被加进组织 | 找负责人加权限 |

## 8. 卡住了怎么办（按这个顺序）

1. **看讲义对应章节** —— 90% 的问题那一章里都讲过（尤其是 ⚠️ 标记处）；
2. **翻附录 A 函数速查表** —— 忘了参数含义、返回值是什么，先查这里；
3. **重跑一次** `Restart & Run All`；
4. **问 AI** —— 但要把「你想干什么 + 完整报错原文 + 已经试过什么」说清楚；
5. **群里问** —— 同样带上上面三样。**只发一句"报错了"没人能帮你。**
