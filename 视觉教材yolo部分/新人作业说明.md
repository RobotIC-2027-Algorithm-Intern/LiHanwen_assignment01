# 视觉培训作业：训练一个目标检测模型

> 这份文件只说清楚**作业是什么、你要交什么**。
> **具体怎么做**，请对照《视觉教材 YOLO 部分》的对应章节（下面每一步都标了该看哪一节）。

------------------------------------------------------------------------

## 一、作业任务

用我们发给你的数据集，**自己训练一个 YOLO26 目标检测模型**，并让它能在**你自己写的推理代码**里跑起来。

------------------------------------------------------------------------

## 二、你会拿到什么

一个数据集文件夹，结构如下：

```text
数据集文件夹/
├── images/
│   ├── train/     ← 980 张训练图片
│   └── val/       ← 197 张验证图片
└── labels/
    ├── train/     ← 与上面一一对应的标签（YOLO .txt 格式）
    └── val/
```

| 项目 | 说明 |
| --- | --- |
| 类别数 | **3 类** |
| 类别名 | `baizi`、`cheli`、`shuiguo`（**顺序不能改**） |
| 标签格式 | `class x_center y_center width height`（已归一化到 0～1） |
| 图片与标签 | **同名一一对应**（`1121.jpg` ↔ `1121.txt`） |

> ⚠️ **注意：数据集里【没有】`dataset.yaml`。** 这是**故意的**——这个文件要你自己写。

------------------------------------------------------------------------

## 三、你要做的事

| # | 做什么 | 看教材哪一节 |
| --- | --- | --- |
| 1 | 检查数据集：图片和标签能不能一一配上 | 2.3.5.3 |
| 2 | **自己写 `dataset.yaml`**（数据路径 + 类别表） | 2.3.6 |
| 3 | 用预训练权重 `yolo26n.pt` 训练模型 | 2.4 |
| 4 | 看懂验证结果（P / R / mAP50 / mAP50-95） | 2.5 |
| 5 | 用 `best.pt` 做推理，并**用 OpenCV 自己画框** | 2.6 |
| 6 | 找出模型的问题（漏检 / 误检），**先人工复核再分类** | 2.7 |
| 7 | 根据分析补数据或改标注，**再训一次、再验证一次** | 2.7.5 |

## 五、几个提醒

- 教材里的示例命令写的是 `data=dataset/dataset.yaml`，而**你拿到的文件夹名字可能不一样**——
  路径要按你自己的实际位置改；
- 训练前先确认**环境与解释器**是对的（教材 2.1、2.1.4.4）；
- 模型效果不好时，**先看错误样本再动手**，不要一上来就加 epoch（教材 2.7.1）；
- 卡住了先翻教材对应章节，再问学长。
