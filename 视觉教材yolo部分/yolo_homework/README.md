## 三、训练与指标（作业第 3、4 步）

**训练设置**：预训练权重 `yolo26n.pt`，50 轮，输入尺寸 640，其余用默认值。

**结果**：

| 指标 | 数值 | 什么意思 |
|---|---|---|
| P（精确率） | 0.990 | 模型框出来的框里，99% 是真的目标，只有 1% 是白框的 |
| R（召回率） | 0.995 | 图里真实存在的目标，模型找到了 99.5%，几乎不漏 |
| mAP50 | 0.994 | 框和答案重叠超过 50% 就算"对"，三类的平均分 |
| mAP50-95 | 0.939 | 要求更严：重叠度从 50% 到 95% 分十档各算一次再平均 |

**两个 mAP 为什么差这么多？**

- `mAP50` 只看"有没有框到"，宽松，所以接近 1.0；
- `mAP50-95` 还要求"框得准不准"，框歪一点分数就掉，所以必然更低。

我们这两个数是 **0.994 / 0.939**，说明**目标基本都找到了，但框的位置还可以更贴边**。

## 四、推理与 OpenCV 画框（作业第 5 步）

`yolo_hw.py` 里**没有用 `results.plot()`**，而是自己做的：

```python
cv2.rectangle(img, (x1, y1), (x2, y2), (0, 200, 0), 3)
cv2.putText(img, f"{类别名}:{置信度}", ...)
```

产物：`out/inference_cv2.jpg`（绿色框 + `cheli:0.87` 这样的标签）。

做法是：先用 `model.predict()` 拿到框，再用 `boxes.xyxy` / `boxes.cls` / `boxes.conf` 三个属性，最后一个一个画到原图上。

## 五、找错与迭代（作业第 6、7 步）

详细过程见 **`report.md`**，这里只说结论。

**第一轮的问题**：误检 25 个（`shuiguo` 19 个最多），漏检 2 个，类别混淆 0 个。
也就是说，模型的主要毛病是"**多框**"，不是"漏检"。

**迭代尝试**：把误检最多的 3 张图当负样本放进训练集，重新训练 50 轮。

**结果**：在**同一份 194 张验证集**上比较，误检从 15 涨到 20，**没有改善**。

**原因**：那 3 张图里其实有 13 个方块，却给了空标签，等于告诉模型"这类画面里没有目标"。负样本只能放真的没有目标的纯背景图。

**收获**：
1. 确认短板是"多框"；
2. 学到负样本的正确用法；
3. 想真正减少误检，应该**补标注**（把边缘的方块也标上），而不是清空标注。
